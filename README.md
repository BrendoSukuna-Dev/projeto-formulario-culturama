## 📋 Sobre o projeto
<p>Este projeto é uma aplicação web focada em coleta de dados, estruturada como uma pesquisa de opinião detalhada. O formulário foi desenhado para ser funcional e intuitivo,
  utilizando elementos semânticos do HTML5 para garantir a correta captura de informações pessoais, hábitos e preferências dos usuários.</p>

## ✦ Principais funcionalidades:

<p>➥ Coleta Estruturada de Dados: Organizado em fieldsets temáticos: Dados Pessoais, Perfil, Hábitos, Opinião e Confirmações.</p>
<p>➥ Variedade de Entradas: Implementação de diversos tipos de input, incluindo:</p>
    •Campos de texto, número, data, email e telefone com validação de padrão (regex).<br> 
    •Upload de arquivos (imagens) com filtro de formato.<br> 
    •Seleção de gênero via botões de rádio e estado civil/estado via listas de seleção.<br> 
    •Seleção múltipla de redes sociais via checkboxes.<br> 
    •Sugestões de estilo musical via datalist e seletor de cor.<br> 
    •Área de texto para comentários e termos de aceite (LGPD).</p>
<p>➥ Validação em Tempo Real: Uso de estados CSS (:valid e :invalid) para dar feedback visual imediato ao usuário.</p>
<p>➥ Acessibilidade: Inclusão de atributos aria-describedby e legendas claras para suporte a tecnologias assistivas.</p>
